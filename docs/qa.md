# 词锚 · 手工回归清单

自动检查（`pnpm verify`）覆盖类型、Lint、类名一致性、纯函数与对话框行为。
**这一份覆盖自动化抓不到的东西**：真实渲染、键盘路径、主题观感、极端内容。

每次改动 UI 后至少跑一遍 A、B 两组；发版前跑完 A–F。

---

## A. 基础四页（每项在 1440 / 768 / 375 三档宽度各看一次）

| # | 场景 | 通过标准 |
| --- | --- | --- |
| A1 | `/` 有数据 | 首屏左侧一句 + 一行统计 + 进度；右侧是「下一份清单」的板面骨架：右列是虚线留白、**没有任何真实释义文本**，连线仍是墨线 |
| A2 | `/` 空库 | 右侧是虚线空态面板（**不是**无边框纯文本 —— 这里曾经有过 `.empty-card` 未定义的回归） |
| A3 | `/lists/` | 账本行；「下一个待练习」行左侧 2px 陶土竖线；页面上只有一个主 CTA；页脚有范围文字与页码条（清单 > 10 份时） |
| A4 | `/words/` | 表格行操作**始终可见**；日期列数字不抖动；页脚页码条可一步跳到任意页 |
| A5 | `/practice/?list=N` | 两列卡片、圆点在卡片边缘、页脚单条 2px 进度轨；顶部有「即时反馈／手动判定」开关 |
| A6 | 横向溢出 | 四页在 375px 与 200% 缩放下都没有横向滚动条 |
| A7 | `/words/` 的「清单」列 | 每行的 `LIST 0N` 与清单页同编号；点击进入对应清单的练习；375px 下日期列隐藏、清单列只剩 `0N ↗`（表头仍写「清单」），不出现横向滚动 |
| A8 | 练习板错排 | 2 / 5 / 20 词的清单各打开两次、各点两次「重新开始」：任何一次都没有「词与释义同行」；同一份清单两次的排布不同 |

## B. 键盘与读屏

| # | 场景 | 通过标准 |
| --- | --- | --- |
| B1 | 首屏 Tab | 第一个落点是「跳到主要内容」，聚焦时浮出；Enter 后焦点进入 `#main-content` |
| B2 | 页头 Tab | 主题三态可聚焦、`aria-pressed` 随选择变化；页头不能盖住被聚焦的元素 |
| B3 | 纯键盘完成一次练习 | Tab 到单词 → Enter 选中 → Tab 到释义 → Enter；全部连对后摘要对话框出现 |
| B9 | 手动判定纯键盘完成 | 全部连好后 Tab 到「判定」→ Enter；卡片转绿后摘要对话框出现；判定按钮在连满前不可聚焦 |
| B10 | 翻页后焦点 | 点页码/上一页/下一页后视口滚到列表顶部、焦点落在列表区块（读屏念出「…第 N 页」），范围文字经 `aria-live` 播报；继续 Tab 依次经过各行（清单 10 行）与页脚页码条；页码按钮报「第 N 页，当前页」；`…` 不可聚焦 |
| B11 | 单词库的清单链接 | Tab 能到达每行的 `LIST 0N` 链接，焦点环可见；可读名称唯一（如「LIST 02，含 serendipity，进入连线练习」），不会 50 行都读成「LIST 01」 |
| B4 | 摘要对话框 | 焦点落在「再练一次」；Tab 只在对话框内循环；Esc 关闭后焦点回到内容区，页面可继续滚动 |
| B5 | 删除单词对话框 | 初始焦点在「再想想」；背景被 `inert`；关闭后焦点回到触发按钮 |
| B6 | 表单报错 | 空提交时错误出现在对应字段下方，焦点跳到第一个出错字段；重复单词报在「单词」字段 |
| B7 | 读屏播报 | 连线反馈（`role=status`）会播报；计时器每秒跳动**不**播报 |
| B8 | 语义 | 单词表可被识别为 table + columnheader；练习卡片读作「{词}，已正确连接」；手动判定未判定时读作「{词}，已连接，待判定」；首页预览的虚线留白不参与读屏 |

## C. 主题

| # | 场景 | 通过标准 |
| --- | --- | --- |
| C1 | 三态切换 | 跟随系统 / 浅色 / 深色 立即生效，`<meta name="theme-color">` 跟随变化 |
| C2 | 持久化 | 选「深色」后刷新仍是深色，且**首帧就是深色**（无白闪） |
| C3 | auto + 系统暗色 | 系统切到暗色时自动跟随；系统切回浅色时也跟随 |

| C5 | 对比度 | 两套主题下用 DevTools 抽查正文、说明文字、状态 pill、连线颜色（含手动判定未判定时的中性线），均 ≥ 4.5:1 |

## D. 内容边界

| # | 场景 | 通过标准 |
| --- | --- | --- |
| D1 | 80 字符单词 | 表格单行截断；练习卡最多 2 行；不撑破布局 |
| D2 | 300 字符释义 | 练习卡 3 行截断且两侧卡片等高；确认对话框内可换行不溢出 |
| D3 | 1000 个单词 | 单词页每页 50 行、共 20 页；翻页与搜索都保持流畅 |
| D4 | 未排满的最后一组 | 清单行显示「未满一组」，练习页顶部有「未满一组」标签 |
| D5 | 缺失清单编号 | `/practice/?list=999` → 空态页，返回清单按钮可用 |
| D6 | 1000 词 / 每组 8 个 | 清单页 125 份清单、13 页，每页 10 行；第 13 页只有 5 行；改「每组单词数」后页码被夹到末页，不出现空白页 |

## E. 深链与状态

| # | 场景 | 通过标准 |
| --- | --- | --- |
| E1 | `/words/?q=seren` | 直接打开即恢复搜索词与结果 |
| E2 | `/words/?q=seren&page=2` | 搜索词与页码同时恢复 |
| E3 | 后退 | 修改搜索词后按浏览器后退，输入框回到上一个词 |
| E4 | 搜索后翻页 | 改搜索词会回到第 1 页；页码参数被清掉 |
| E5 | 反馈方式持久化 | 清单页切到「手动判定」后刷新仍是手动；练习页顶部开关同步显示，切换后两端一致 |
| E6 | `/lists/?page=2` | 直接打开即停在第 2 页；刷新、浏览器后退/前进与 URL 一致；`/lists/?page=abc` 归一到第 1 页；第 1 页的 URL 不保留 `page=1` |
| E7 | 下一组提示 | 下一组不在当前页时，页脚出现「下一组在第 N 页 →」，点击跳到该页并滚到列表顶部；下一组就在当前页时提示消失 |
| E8 | `from=words` 深链 | 从单词库某行点击进入的 `/practice/?list=N&from=words`，左上角返回链接写「单词库」并回到 `/words`；无 `from` 或取值非法时仍写「学习清单」；完成后「下一份清单」仍保留 `from=words`，没有下一份时按钮为「返回单词库」 |

## G. Anki 收录

| # | 场景 | 通过标准 |
| --- | --- | --- |
| G1 | 字段映射 | 设置里选好单词／释义字段后，「测试：预览当前卡片」显示的就是这两段文本；两项留空时回落到笔记类型的第 1、2 个字段 |
| G2 | 只收「重来」 | 依次按「重来 / 困难 / 好 / 简单」，菜单显示待发送 **1** 个；按「好 / 简单」的卡片不进队列 |
| G3 | 深链收录 | 「打开词锚收录（3）」→ 新标签页横幅「已收录 3 个单词」，地址标注的 `#inbox=` 已被清掉；同时开着的清单页即时出现新词；刷新不会重复入库 |
| G4 | 剪贴板收录 | 「复制到剪贴板」→ 单词库「从剪贴板收录」→ 报「已收录 3 个单词」；再点一次报「这 3 个单词都已在词库中，没有新增」，表格无重复行、原释义未被覆盖 |
| G5 | 通道降级 | 把 `max_deep_link_chars` 调到 300，再点「打开词锚收录」→ 不打开页面，弹提示并已复制到剪贴板 |
| G6 | 坏 payload | 手工打开 `/#inbox=!!!!` → 红色横幅「收录失败：收录内容无法解码」，地址标注被清空，词库数量不变 |
| G7 | 横幅与面板的形状 | 375px 下不出现横向滚动；Tab 可到 textarea 与两个按钮；深色主题下横幅、状态文字对比度 ≥ 4.5:1；页头下方的横幅可关闭 |

## 快速自检命令

```bash
pnpm verify                     # 类型 + lint + 类名 + 单测 + 构建

# Anki 插件的线格式与字段清洗（不需要 Anki）
python -m unittest discover anki-addon/tests

# 有 agent-browser 时，四页无障碍审计
for p in "" "lists/" "words/" "practice/?list=1"; do
  npx agent-browser a11y "http://localhost:3000/$p"
done
```
