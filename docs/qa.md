# 词锚 · 手工回归清单

自动检查（`pnpm verify` / `pnpm test:rust` / `pnpm test:addon`）覆盖类型、Lint、类名一致性、纯函数、组件行为、payload 校验与原子写。
**这一份覆盖自动化抓不到的东西**：真实窗口、托盘、WebView2、Anki 交互、主题观感、极端内容。

每次改动 UI 后至少跑一遍 A、B 两组；发版前跑完 A–H。

## G. 桌面端与 Anki 推送（发版前必跑）

自动检查只覆盖「校验函数正确」和「收件箱原子写」；下面这些要真的开两个应用。

| # | 场景 | 通过标准 |
| --- | --- | --- |
| G1 | 冷启动 | 托盘出现词锚图标；窗口 1100×760；界面完整；`%APPDATA%\word-anchor\port` 里是 8770..8789 之间的端口；「单词库 → 桌面端」显示「本地接口已就绪」 |
| G2 | 实时推送 | Anki 按「重来」→ 1 秒内单词库出现该词；横幅报「已收录 1 个单词」；清单按 FIFO 重排；`inbox` 目录为空 |
| G3 | 语义正确（又忘了） | 对一个已收录且所在组已练完的词再按「重来」→ 横幅报「1 个单词重新排到了队尾」；它原组仍「已完成」，末组变「待练习」且里面有它；单词库里该词跳到最后一行 |
| G4 | 语义正确（重发） | 预览队列 →「重新发送全部」→ 只报「这 N 个单词都已在词库中，没有新增」；单词顺序与各组的完成状态一个都没变 |
| G5 | 离线接收 | 完全退出词锚（托盘里也没有）→ 按两次「重来」→ Anki 无弹窗、队列保留（预览里都是「待发送」）；启动词锚 → 界面出现后立即补收、横幅报数、`inbox` 清空 |
| G6 | 端口冲突 | 先用别的程序占住 8770 → 启动词锚 → 应用改用 8771，端口文件更新为 8771，桌面端区显示 8771；Anki（API 地址留空）推送仍成功 |
| G7 | 手动兜底 | 关掉「自动推送」→ 按「重来」只入队、不推送；菜单「立即推送（1 个待发送）」→ 提示「已推送 1 个单词」并入库 |
| G8 | 超限批次 | 队列里塞 >200 条（或连按 200+ 次「重来」）→ 推送只送前 200 条、其余仍待发送，下一轮自动接着推；用 curl 发一个 201 条的 payload → 400，插件不标记已发送、`error.log` 有记录、队列仍在 |
| G9 | 备份 | 系统「另存为」导出 JSON；再导入旧网页版备份 → 词库/统计/设置完整恢复；导入只差大小写的重复词 → 提示「出现了不止一次」并拒绝 |
| G10 | 回归 | 连线练习（拖拽/点击/键盘/即时与手动判定）、趣味复习、分页、搜索、主题三态、删除多词全部正常 |
| G11 | 单实例与托盘 | 关闭窗口 → 窗口消失、托盘还在，此时 Anki 推送仍实时入库；重复启动 exe → 不出现第二个窗口，已有窗口被聚焦 |
| G12 | 数据位置 | 卸载重装（或删 `%LOCALAPPDATA%\top.kariscode.wa\`）后 `%APPDATA%\top.kariscode.wa\word-anchor.db` 仍在、词库不丢；「桌面端」区「测试连接」显示「连接正常」 |
| G13 | 插件设置 | 「测试连接」在词锚关闭时给出可读失败原因；字段映射用「测试：预览当前卡片」核对；牌组白名单外的卡片按「重来」不入队 |
| G14 | 静默失败 | 词锚关闭时推送 → Anki 不弹窗、复习不卡；`user_files/error.log` 里有 `推送未完成：network_error`；重启词锚后下次「重来」自动补上 |

## A. 基础五页（每项在 1440 / 768 / 375 三档宽度各看一次）

> 桌面窗口最小 900px；375px 一档用浏览器预览（`pnpm dev`）或 DevTools 设备模式检查。

## B. 键盘与读屏

| # | 场景 | 通过标准 |
| --- | --- | --- |
| B1 | 首屏 Tab | 第一个落点是「跳到主要内容」，聚焦时浮出；Enter 后焦点进入 `#main-content` |
| B2 | 页头 Tab | 主题三态可聚焦、`aria-pressed` 随选择变化；页头不能盖住被聚焦的元素 |
| B3 | 纯键盘完成一次练习 | Tab 到单词 → Enter 选中 → Tab 到释义 → Enter；全部连对后摘要对话框出现 |
| B9 | 手动判定纯键盘完成 | 全部连好后 Tab 到「判定」→ Enter；卡片转绿后摘要对话框出现；判定按钮在连满前不可聚焦 |
| B10 | 翻页后焦点 | 点页码/上一页/下一页后视口滚到列表顶部、焦点落在列表区块（读屏念出「…第 N 页」），范围文字经 `aria-live` 播报；继续 Tab 依次经过各行（清单 10 行）与页脚页码条；页码按钮报「第 N 页，当前页」；`…` 不可聚焦 |
| B11 | 单词库的清单链接 | Tab 能到达每行的 `LIST 0N` 链接，焦点环可见；可读名称唯一（如「LIST 02，含 serendipity，进入连线练习」），不会 50 行都读成「LIST 01」 |
| B12 | 编辑对话框 | Tab 只在对话框内循环；Esc 关闭且不保存；关闭后焦点回到该行铅笔按钮；触屏打开时焦点落在「取消」，不自动弹出键盘 |
| B4 | 摘要对话框 | 焦点落在「再练一次」；Tab 只在对话框内循环；Esc 关闭后焦点回到内容区，页面可继续滚动 |
| B5 | 删除单词对话框 | 初始焦点在「再想想」；背景被 `inert`；关闭后焦点回到触发按钮 |
| B13 | 批量删除 | Tab 能到表头复选框与每一行复选框，可读名称唯一（「选中本页全部单词」/「选择 serendipity」）；部分选中时表头是 mixed；操作条的「已选 N 个词」经 `aria-live` 播报；确认框初始焦点在「再想想」、背景 `inert`、Esc 关闭后焦点回到「删除选中」，确认后读出「已删除 N 个单词。」 |
| B14 | 桌面端区 | Tab 依次经过「测试连接」与自启开关；开关可读名称含「开机自启」、`aria-checked` 随状态变化；连接结果/错误经 `role=status` 播报 |
| B6 | 表单报错 | 错误出现在对话框内对应字段下方，焦点跳到第一个出错字段；重复单词报在「单词」字段，对话框不关闭 |
| B7 | 读屏播报 | 连线反馈（`role=status`）会播报；计时器每秒跳动**不**播报；收录横幅（`role=status` / 错误时 `role=alert`）会播报 |
| B8 | 语义 | 单词表可被识别为 table + columnheader；练习卡片读作「{词}，已正确连接」；手动判定未判定时读作「{词}，已连接，待判定」；首页预览的虚线留白不参与读屏 |

## D. 内容边界

| # | 场景 | 通过标准 |
| --- | --- | --- |
| D1 | 80 字符单词 | 表格单行截断；练习卡最多 2 行；不撑破布局 |
| D2 | 300 字符释义 | 练习卡 3 行截断且两侧卡片等高；确认/编辑对话框内长文本不溢出 |
| D3 | 1000 个单词 | 单词页每页 50 行、共 20 页；翻页与搜索都保持流畅；一次落盘（改任意词）后重启仍在 |
| D4 | 未排满的最后一组 | 清单行显示「未满一组」，练习页顶部有「未满一组」标签 |
| D5 | 缺失清单编号 | `/practice/?list=999` → 空态页，返回清单按钮可用 |
| D6 | 1000 词 / 每组 8 个 | 清单页 125 份清单、13 页，每页 10 行；第 13 页只有 5 行；改「每组单词数」后页码被夹到末页，不出现空白页 |
| D7 | 完成状态按词记 | 练完一组后改「每组单词数」重新切分：全由练过的词组成的组仍是「已完成」，含没练过的词的组回到「待练习」；单词库底部的「N 个词练过」跟着变 |
| D8 | 批量删除与清单重排 | 跨页选中 60 个词并删除：剩余清单编号连续无空洞、末组「未满一组」标记正确；含没练过的词的组回到「待练习」，全由练过的词组成的组仍是「已完成」 |
| D9 | 落盘失败提示 | 把 `word-anchor.db` 改成只读（或占住文件）→ 改一个词 → 顶部出现「本地保存失败…词库现在只在内存里…」；恢复权限后再次改动仍能保存 |

## F. 动效与性能

| # | 场景 | 通过标准 |
| --- | --- | --- |
| F1 | `prefers-reduced-motion: reduce` | 每屏入场不播（内容首帧就在位）、无落定位移；连线即时出现；「测试连接」的旋转图标与占位页的锚形呼吸都静止 |
| F2 | 滚动 | 胶囊 sticky 且**不透明**（没有毛玻璃）；它背后是一条与页面同色的不透明带，滚动时内容在带子下沿被整齐裁断，**不会从胶囊两侧或上方穿过去**（把这条带子删掉就会长出碎片式的内容，看着像渲染错误）；无整屏噪点层参与重绘 |
| F3 | Lighthouse（浏览器预览 out/） | 四页 Accessibility ≥ 95，无新的 best-practice 回归 |
| F4 | `axe` | `agent-browser a11y <url>` 在浅色与深色下均为 0 violations |
| F5 | 启动时间 | 冷启动到可交互 ≤ 3 秒（含 Rust 绑端口）；`inbox` 里有 50 个文件时补收仍 ≤ 1 秒 |
| F6 | 每屏入场 | 五个页面各进一次：标题 → 主体 → 控件按 80ms 阶梯上浮淡入，**只跑一次**；换页（清单↔单词库↔趣味复习）时重建页面会重播；不动任何布局尺寸 |
| F7 | 连线状态 | 点选或拖拽连上一条线：实线用 240ms 从起点绘制到落点（`pathLength="1"` + `stroke-dashoffset`）；连对时圆点 160ms 落锁；连错时改红色虚线并淡入 |

## H. 趣味复习

| # | 场景 | 通过标准 |
| --- | --- | --- |
| H1 | 均匀登场 | 5 个词各点「重新开始」几次：每局都是 10 题，每个词恰好出现在两题；6 个词时每个词出现 1 或 2 次，次数差 ≤ 1；相邻两题永远不是同一个词 |
| H2 | 小词库降级 | 2 / 3 / 4 个词分别出 4 / 6 / 8 题、2 / 3 / 4 个选项；只有 1 个词时页面直接给空态，不出现只有正确项的题 |
| H3 | 同义释义 | 两个词填同一条释义：选项里该释义只出现一次，不会出现两个字面一样的按钮 |
| H4 | 判定与前进 | 点对：选项转绿、出现对勾，0.9s 后自动下一题；点错：选项转红、正确项同时标绿、其余选项退到灰，反馈区写「正确答案：…」，1.6s 后前进；两种情况下「下一题」都能立即前进 |
| H5 | 键盘 | 数字键 1–4 可作答；判定后 Enter / Space 立即前进；连按同一个选项不会重复计分；答完一局后 Enter 不会误触上一题的选项 |
| H6 | 结算 | 第 10 题判定后弹出「本局结束」：答对数、正确率、用时、最高连击与本局一致；答错的词按去重列表给出正确释义，错两次标 `×2`；Esc 关闭后页面仍有「再来一局」 |
