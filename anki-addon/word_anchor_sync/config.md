# 词锚同步配置

推荐直接用 **Tools → 词锚 Word Anchor → 设置…** 改，那里会列出当前词库的字段名与牌组。
想手工改配置的话，这里的每一项含义如下。

- `site_url`：词锚部署地址，例如 `https://someone.github.io/word_anchor/`。
  留空时「打开词锚收录」会先提示你填。
- `term_field`：单词所在的字段名。留空 = 自动取笔记类型的第 1 个字段。
- `meaning_field`：释义所在的字段名。留空 = 自动取第 2 个字段。
- `deck_whitelist`：牌组白名单，例如 `["英语", "日语::生词"]`。
  留空（默认）= 所有牌组都收录；非空时只有名单里的牌组才收「重来」。
  名字不分大小写，可以手写，但推荐用 **设置…** 里的勾选列表。
  白名单只影响之后按下的「重来」——已经在 `queue.json` 里的条目不会自己消失，
  不想要就打开 **预览队列 → 清空队列**。
- `deck_whitelist_subdecks`：默认 `true`，表示勾了 `英语` 也收 `英语::单词`
  （只认 `::` 子树；`英语角` 这种同前缀的牌组不算）。
  改成 `false` 就只认完全一致的牌组名。
- `max_deep_link_chars`：深链整条 URL 的字符上限。超过就自动降级成剪贴板通道。
- `capture_enabled`：设为 `false` 可以临时关掉「按重来就收录」。
- `strip_term_prefixes` / `strip_meaning_prefixes`：字段内容开头常带的标签，
  例如 `释义：意外发现…`、`单词：lucid`、`【释义】清晰易懂的`。
  这些标签会在入库前被去掉（字段名本身也会自动加进名单）。
  只去掉「标签 + 分隔符（`：` `:` `-` `—` 空格 换行）」或者被
  `【】[]（）` 包住的那一层，正文不会被误伤。
  如果某个词真的以这些字开头（比如释义词条本身就叫「释义」），
  把它从列表里删掉即可。

队列文件在插件目录的 `user_files/queue.json`，报错日志在同目录的 `error.log`。
