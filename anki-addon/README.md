# 词锚同步 · Anki 插件

复习时按 **重来**，单词和释义就悄悄进队列；到学习时间，一条命令把它们送进词锚。

> 词锚是纯静态站点，词库只存在浏览器（IndexedDB）里，插件不会、也无法直接改仓库文件。
> 它只做一件事：把「单词 + 释义」送到浏览器门口——要么写进剪贴板，要么拼成一条深链。

## 安装

**方式一：直接复制文件夹（推荐，改代码后重启 Anki 即生效）**

1. Anki 菜单 **工具 → 附加组件 → 查看文件**，会打开 `addons21` 文件夹。
2. 把本目录下的 `word_anchor_sync/` 整个复制进去。
3. 重启 Anki。**工具** 菜单里出现 **词锚 Word Anchor** 就成功了。

> 更新插件时请**覆盖文件**，不要删掉整个 `word_anchor_sync/` 再复制：
> 待收录队列在 `word_anchor_sync/user_files/queue.json`，删目录会一起没。
>
> 复制文件**不会**刷新插件目录里的 `meta.json`（Anki 实际读的是它，里面有你的设置）。
> 改名、改版本范围这类元数据改动后，要么用「方式二」重装一次，要么手动把
> `meta.json` 的对应字段改掉再重启。

**方式二：打包成 `.ankiaddon`**

```bash
python anki-addon/build.py
# 生成 anki-addon/dist/word-anchor-sync.ankiaddon，双击即可安装
```

## 一次性设置

**工具 → 词锚 Word Anchor → 设置…**

1. **词锚站点地址**：例如 `https://<你的用户名>.github.io/word_anchor/`
   （只填 `用户名.github.io/word_anchor` 也行，会自动补 `https://` 和结尾 `/`）。
2. **单词字段 / 释义字段**：下拉框里是当前词库所有笔记类型的字段名。
   留空 = 自动取笔记类型的第 1、2 个字段。
3. **牌组白名单**：在下半部分的列表里勾上你要收的牌组（例如你的单词牌组）。
   **一个都不勾 = 所有牌组都收**，语法卡、句子卡会跟着混进来，所以建议至少勾一个。
   勾了父牌组等于连子牌组一起收（`英语` 含 `英语::单词`，但不含 `英语角`）。
4. 点 **确定** 之前，先去复习界面用 **测试：预览当前卡片** 看一眼抓出来的内容对不对。

## 日常流程

```
Anki 复习 ──按「重来」──▶ 队列（user_files/queue.json）
                              │
                  ┌───────────┴────────────┐
        「打开词锚收录」                「复制到剪贴板」
                  │                        │
     打开 站点/#inbox=<payload>      词锚 → 单词库 →「从剪贴板收录」
                  │                        │
                  └──────▶ 浏览器 IndexedDB ◀──┘
```

- **打开词锚收录（N 个待发送）**：打开一个新标签页，页面自己入库，横幅报「已收录 N 个单词」，
  地址栏里的 payload 会立刻被清掉；同时开着的清单页通过 `BroadcastChannel` 当场更新。
- **复制到剪贴板（N 个待发送）**：词锚「单词库」页 →「从 Anki 快速收录」→ 点「从剪贴板收录」。
- 队列超过 `max_deep_link_chars`（默认 1600 字符）时，深链会自动降级成剪贴板通道。
- 发送过的条目**不会删除**，只标记 `sentAt`；词锚按单词去重，重发是幂等的：
  条目带着上次的 `capturedAt`，同一个时间戳再送一遍只会被去重，不会变更词序。
  误关了标签页时用 **预览队列 → 重新发送全部** 补救。
- 词库里已经有的词，你又按了一次 **重来**，词锚会把它**挪到队尾**并清掉「练过」的标记，
  于是它会在最新一组里再被练一次。新抓取与重发靠 `capturedAt` 区分：
  时间更新才算「又忘了」，时间没变（重发）只去重。

## 队列与日志

| 文件 | 说明 |
| --- | --- |
| `word_anchor_sync/user_files/queue.json` | 待收录队列，按单词去重，原子写盘 |
| `word_anchor_sync/user_files/error.log` | 异常日志（只留尾部 20KB） |

`user_files/` 在插件更新时不会被覆盖。

## 故障排查

| 现象 | 处理 |
| --- | --- |
| 工具菜单里没有「词锚」 | 插件没被加载：看 **工具 → 附加组件** 里是否启用；或重启 Anki |
| 附加组件列表里词锚是灰的，或提示「需要旧版本的 Anki」 | `max_point_version` 写成了负数。Anki 把负数读成「`abs(n)` 是最后一个支持的版本」，`-1` 就等于「只支持 Anki 2.1.1」，插件会被静默跳过。仓库里已是 `0`（无上限）；如果 `meta.json` 里还留着旧的 `-1`，改成 `0` 再重启 |
| 菜单项是灰的 | 队列为空（只有按「重来」才会进队列） |
| 按了「重来」但没进队列 | 用 **测试：预览当前卡片** 看提示：牌组不在白名单 → 设置里勾上；`capture_enabled` 为 `false`；或这张卡只有一个字段 / 第二个字段是空的（这两种读不出释义，会被跳过） |
| 点「打开词锚收录」没反应 | 站点地址没填，或浏览器没起来；改用「复制到剪贴板」 |
| 词锚页面显示「收录失败」 | payload 被截断：改用剪贴板通道（整段复制不会截断） |
| 抓到的释义不对 | 设置里重新选字段，用「测试：预览当前卡片」确认 |
| 释义开头多出「释义：」这类标签 | 插件会在入库前去掉它（`【释义】`、`释义：`、以字段名开头的都算），旧队列里的条目也会在发送时自动清洗；仍没去掉就把那个词加进配置里的 `strip_meaning_prefixes` |
| 想临时停掉收录 | 设置里把 `capture_enabled` 改成 `false`（附加组件 → 配置） |

## 兼容性

- 需要 **Anki 桌面版 ≥ 2.1.50**（`user_files`、Qt6）。
- AnkiMobile、AnkiWeb 加载不了插件，手机上按「重来」不会进队列。
- 只收录 **重来（Again / ease = 1）**，不含「困难」。
- 默认不限制牌组；在 **设置…** 里勾了牌组白名单后，只有勾中的牌组才收录。

## 开发

```bash
python -m unittest discover anki-addon/tests   # 线格式 + 字段清洗（不需要 Anki）
python anki-addon/build.py                     # 打包
```

`wire.py` 里的常量与 JSON 结构必须与站点 `src/lib/intake.ts` 完全一致；
两边的测试都覆盖了「编码 → 解码」以及一段由真实插件产出的 fixture。
