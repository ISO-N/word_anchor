# 词锚同步 · Anki 插件

复习时按 **重来**，单词和释义就悄悄进队列，并在后台推给本机的词锚桌面端。不打开网页、不经过剪贴板、不联网。

> 词锚是 Tauri 桌面应用（Windows），词库在 `%APPDATA%\top.kariscode.wa\word-anchor.db`。
> 插件只往 `127.0.0.1` 送数据；桌面端没开时，推送静默失败、队列保留，下次再试。

## 安装

**方式一：直接复制文件夹（推荐，改代码后重启 Anki 即生效）**

1. Anki 菜单 **工具 → 附加组件 → 查看文件**，会打开 `addons21` 文件夹。
2. 把本目录下的 `word_anchor_sync/` 整个复制进去。
3. 重启 Anki。**工具** 菜单里出现 **词锚 Word Anchor** 就成功了。

> 更新插件时请**覆盖文件**，不要删掉整个 `word_anchor_sync/` 再复制：
> 待收录队列在 `word_anchor_sync/user_files/queue.json`，删目录会一起没。
>
> 复制文件**不会**刷新插件目录里的 `meta.json`（Anki 实际读的是它，里面有你的设置）。
> 改名、改版本范围这类元数据改动后，要么用「方式二」重装一次，要么手动把
> `meta.json` 的对应字段改掉再重启。

**方式二：打包成 `.ankiaddon`**

```bash
python anki-addon/build.py
# 生成 anki-addon/dist/word-anchor-sync.ankiaddon，双击即可安装
```

## 一次性设置

**工具 → 词锚 Word Anchor → 设置…**

1. **词锚 API 地址**：**建议留空**——插件会自动读词锚写下的端口文件（`%APPDATA%\word-anchor\port`），
   端口被占用而顺延也能找到。只有想指向别的机器/端口时才手填，例如 `127.0.0.1:8771`。
   旁边的 **测试连接** 会真的打一次 `GET /api/v1/health`。
2. **按「重来」后自动推送**：默认开。关掉后只入队，等菜单里的「立即推送」或启动补推。
3. **单词字段 / 释义字段**：下拉框里是当前词库所有笔记类型的字段名。
   留空 = 自动取笔记类型的第 1、2 个字段。
4. **牌组白名单**：在下半部分的列表里勾上你要收的牌组（例如你的单词牌组）。
   **一个都不勾 = 所有牌组都收**，语法卡、句子卡会跟着混进来，所以建议至少勾一个。
   勾了父牌组等于连子牌组一起收（`英语` 含 `英语::单词`，但不含 `英语角`）。
5. 点 **确定** 之前，先去复习界面用 **测试：预览当前卡片** 看一眼抓出来的内容对不对。

## 日常流程

```
Anki 复习 ──按「重来」──▶ 队列（user_files/queue.json）
                              │
                    auto_push 打开时，后台线程立刻
                              │
                              ▼
              POST http://127.0.0.1:<port>/api/v1/intake
                              │
              ┌───────────────┴───────────────┐
          200 成功                        失败（未开 / 超时 / 400）
              │                               │
      词锚收件箱 inbox/*.json           队列保留（不标记已发送）
              │                               │
      WebView 实时入库 + 横幅报数      下次「重来」/ 启动延时 / 菜单手动重试
```

- 推送**永远在后台线程**，回主线程才动队列与 Qt；任何异常只写 `error.log`，不打断复习。
- 发送过的条目**不会删除**，只标记 `sentAt`；词锚按单词去重，重发是幂等的。
- 队列里已经有的词又按了一次 **重来** → `capturedAt` 刷新、`sentAt` 清空，下次会把新时间推过去，
  词锚据此把它**挪到队尾**并清掉「练过」标记。
- 菜单项：**立即推送（N 个待发送）**、**预览队列（共 N 个）**、**测试：预览当前卡片**、**设置…**。
  预览窗口里还有「重新发送全部」（把 `sentAt` 全清掉再推一次）和「清空队列」。

## 队列与日志

| 文件 | 说明 |
| --- | --- |
| `word_anchor_sync/user_files/queue.json` | 待收录队列，按单词去重，原子写盘 |
| `word_anchor_sync/user_files/error.log` | 异常与推送失败记录（只留尾部 20KB） |

`user_files/` 在插件更新时不会被覆盖。

## 配置项（`config.json`）

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `api_base` | `""` | 词锚 API 基地址；留空 = 自动发现端口 |
| `auto_push` | `true` | 按「重来」后立刻后台推送 |
| `push_timeout` | `2.0` | 单次 HTTP 超时（秒），限制在 0.5–10 |
| `term_field` / `meaning_field` | `""` | 留空 = 笔记类型第 1、2 个字段 |
| `deck_whitelist` | `[]` | 牌组白名单，空 = 全收 |
| `deck_whitelist_subdecks` | `true` | 白名单是否包含子牌组 |
| `capture_enabled` | `true` | `false` 时「重来」完全不收录 |
| `strip_term_prefixes` / `strip_meaning_prefixes` | 见文件 | 字段内容自带的标签，入库前去掉 |

## 故障排查

| 现象 | 处理 |
| --- | --- |
| 工具菜单里没有「词锚」 | 插件没被加载：看 **工具 → 附加组件** 里是否启用；或重启 Anki |
| 附加组件列表里词锚是灰的，或提示「需要旧版本的 Anki」 | `max_point_version` 写成了负数。Anki 把负数读成「`abs(n)` 是最后一个支持版本」，`-1` 就等于「只支持 Anki 2.1.1」，插件会被静默跳过。仓库里已是 `0`（无上限）；如果 `meta.json` 里还留着旧的 `-1`，改成 `0` 再重启 |
| 菜单项是灰的 | 队列为空（只有按「重来」才会进队列） |
| 按了「重来」但没进队列 | 用 **测试：预览当前卡片** 看提示：牌组不在白名单 → 设置里勾上；`capture_enabled` 为 `false`；或这张卡只有一个字段 / 第二个字段是空的（这两种读不出释义，会被跳过） |
| 「测试连接」失败 | 词锚桌面端没在运行；或「API 地址」手填错了。清空地址让它自动发现，再确认托盘里有词锚图标 |
| 推送失败但没提示 | 这是刻意的：复习时不弹窗。打开 `user_files/error.log` 看 `推送未完成：…` 那一行；下拉菜单 **立即推送** 会给出提示框 |
| 词锚显示「收录失败」 | 推的是坏 payload（结构不对/超过 200 条）。预览队列里能看到待发内容；超过 200 条时分批推送即可（插件一次最多送 200 条，剩下的留在队列） |
| 抓到的释义不对 | 设置里重新选字段，用「测试：预览当前卡片」确认 |
| 释义开头多出「释义：」这类标签 | 插件会在发送前去掉它（`【释义】`、`释义：`、以字段名开头的都算），旧队列里的条目也会在发送时自动清洗；仍没去掉就把那个词加进配置里的 `strip_meaning_prefixes` |
| 想临时停掉收录 | 设置里取消「自动推送」，或把配置里的 `capture_enabled` 改成 `false` |

## 兼容性

- 需要 **Anki 桌面版 ≥ 2.1.50**（`user_files`、Qt6）。
- AnkiMobile、AnkiWeb 加载不了插件，手机上按「重来」不会进队列。
- 只收录 **重来（Again / ease = 1）**，不含「困难」。
- 默认不限制牌组；在 **设置…** 里勾了牌组白名单后，只有勾中的牌组才收录。

## 开发

```bash
python -m unittest discover anki-addon/tests   # wire + sender + 字段清洗（不需要 Anki）
python anki-addon/build.py                     # 打包
```

- `wire.py` 的 JSON body 与桌面端 `src/lib/intake.ts`、Rust `src-tauri/src/api.rs` **完全一致**；
  三边各有一份单测，并用同一个 fixture 字符串锁住格式。
- `sender.py` 只依赖标准库（`urllib`），transport 可注入，因此成功/失败/超时/400 都能脱离 Anki 测。
- 任何改动都不要在 `wire.py` / `sender.py` / `capture.py` 里 `import aqt`，否则单测会跑不起来。
